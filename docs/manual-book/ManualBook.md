# MANUAL BOOK QUOTEFLOW
## Panduan Penggunaan Sistem & Data Master

Dokumen ini berisi panduan operasional lengkap untuk aplikasi **QuoteFlow**, mulai dari proses autentikasi (login), navigasi dashboard utama, hingga pengelolaan seluruh modul Master Data secara terperinci.

---

## 1. PENDAHULUAN & AUTENTIKASI (LOGIN)
Untuk mengakses sistem QuoteFlow:
1. Buka URL aplikasi di browser ().
2. Masukkan **Username** atau email ().
3. Masukkan **Password** akun yang valid.
4. Klik tombol **Masuk** untuk masuk ke sistem. Sistem akan menyimpan token sesi dan mengarahkan pengguna ke halaman Dashboard Utama.
